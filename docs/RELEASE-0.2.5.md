# 0.2.5：簡體中文續關與魚獲確認

- GUI 增加遊戲語言選項：簡體中文、繁體中文、自動識別；命令列也可使用 `--language`。
- 以魚獲卡片的紙面及 `GET!` 徽章雙重確認釣獲，不把拉扯 HUD 消失誤計為成功。介面顯示累計魚獲和連續成功局數；本機診斷可保存每次魚獲畫面。
- 確認魚獲卡片後，即使「繼續」字形在淡入動畫中暫時不可辨識，也可在卡片固定的右下續關位置重試。關閉新圖鑑及獎勵的原有判斷保持優先。
