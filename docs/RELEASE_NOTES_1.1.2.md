## English

- Automatically saves custom start and stop shortcuts and restores them before registering the listener on startup.
- Ignores outdated registration reports so the activity log reflects the currently configured shortcut.

## 繁體中文

- 自動保存自訂的開始與停止快捷鍵，啟動時先讀取設定再註冊。
- 忽略過期的註冊訊息，讓執行記錄顯示目前設定的快捷鍵。
