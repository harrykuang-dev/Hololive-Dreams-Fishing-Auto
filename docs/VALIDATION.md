## 合成控制基準

`python tools/control_benchmark.py` 搜尋 27 組參數，12 條訓練軌跡與 50 條獨立軌跡。
人工模型的最優參數為 `kp=4, kd=0.65, lead=0.08, deadband=0.012`。
獨立軌跡平均重疊時間比例 0.899827，最低 0.772506。
**重疊時間比例不是釣獲成功率**；人工物理模型沒有遊戲規則、真實擷取／输入延遲或魚種行為。
上述參數沒有自動套用到本機 profile，避免把人工模型的結果當成實機調校。

## 本次阻礙

Computer Use 插件技能要求通过 `node_repl` JavaScript 使用 `@oai/sky`。
本次可呼叫工具中沒有 `node_repl`，因而不能自行查看教學或操作已開啟的遊戲。
沒有以 shell 自製 UI 工具繞過；只編寫供使用者執行的程式並完成離線驗證。
官方新區域公告確認釣魚存在，但不含足夠的輸入规则，故程式中的控制假設明確保留待驗證。

後續若能使用 Computer Use，應從讀取當前遊戲畫面開始，不假設本機已校準，也不把以上測試當實戰。
