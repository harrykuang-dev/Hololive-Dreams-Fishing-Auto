# 0.1.1 驗證紀錄（2026-09-29）

狀態：**0.1.0 已完成遊戲規則確認、實機校準與多輪測試；0.1.1 的續竿按鈕辨識已用使用者提供的結果畫面核對**。

## 已確認規則

- 魚上鉤時，點擊畫面開始拉扯小遊戲。
- 長按捲線器會讓黃色控制塊快速上升；放開會快速下降。
- 接近魚時快速連點，可讓控制塊以較小幅度上升。
- 魚位於黃色控制塊範圍內時，右側計量條增加；滿格後釣獲成功。

## 實機驗證

- 成功辨識短暫出現的 `TAP!`，實測畫面中只維持約 0.3–0.4 秒。
- 拉扯畫面的魚、黃色控制塊及完整垂直軌道已使用真實遊戲畫面校準。
- 魚遮住控制塊中段時，縱向接合仍可保持追蹤；提供的錄影回放中辨識 239/240 幀。
- 已實際釣獲沙丁魚、蝦蛄、海星、隆頭魚等不同魚種；包含 2 星、434.8g 隆頭魚。
- 快速連點版一輪拉扯約 5.9 秒完成，並成功自動按「繼續」進入下一竿。
- 已排除收竿動畫、魚獲結果圖、紅色魚類及 `NEW!` 標記造成的主要誤判。

## 控制策略

控制器依魚與黃色控制塊的預測相對位置使用三段模式：

1. 控制塊明顯低於魚：持續長按，快速上升。
2. 控制塊明顯高於魚：完全放開，快速下降。
3. 兩者接近：以約 2.5–13 Hz 的動態短脈衝連點，降低上下過衝。

## 安全行為

- 只綁定標題完全相符的 `hololive-Dreams` 視窗。
- 視窗失焦時立即放開滑鼠並停止，避免輸入落到其他程式。
- 停止、關閉 GUI 或發生例外時，最後處理一定會釋放程式持有的滑鼠按鍵。
- 不讀取或修改遊戲記憶體、存檔或程序。
- 結果頁右下「繼續」按鈕連續辨識 0.2 秒後自動點擊，避免短暫的動畫誤判。

提供的 1664×973 結果畫面中，右下藍色按鈕辨識中心約為 `(1382, 892)`；0.1.1 將穩定辨識 0.2 秒設為點擊條件。此新等待時間尚未在額外的實機連續釣魚輪次中驗證。

## 限制

本次測試證明目前版本與測試畫面可運作，不代表所有未來遊戲版本、顯示縮放、解析度及魚種永久 100% 成功。若 UI 配色、拉扯軌道位置或物理參數變更，需要重新校準或調整閾值。
