# v0.3.1：不同畫面配色下的自動續局修復

使用者提供的拍屏影片中，「繼續」按鈕呈藍紫色，超出原本青藍色遮罩；魚獲卡片也較暗，原本紙色門檻使卡片確認失敗。在同一段經遊戲區域透視校正的離線回放中，v0.3.0 沒有產生模擬續局點擊。

- 導覽按鈕及關閉 X 支援青藍至藍紫色，仍要求既有形狀、白框和字形證據。
- 只對結算卡片和按鈕局部放寬亮度限制；魚獲仍需 GET 標題和卡片結構，沒有 GET 的紙色區域不會觸發續局。
- 不修改 TAP 咬鉤遮罩、拉扯控制及未知畫面保護。
- 離線回放工具新增 `--client-quad`，用於拍屏素材校正；實際釣魚程式不使用拍屏或透視轉換。

驗證：77 項離線測試通過，新增三項回歸測試涵蓋藍紫按鈕、多尺寸、低亮度、缺字形、波浪背景和圖鑑優先關閉。使用者影片以 10Hz 回放，97 幀確認魚獲卡片，模擬點擊落在右下「繼續」內；舊版同段沒有模擬續局點擊。照片及影片結算幀在 50%、75%、100%、150% 尺寸下均識別成功。568 張既有場景采樣圖與 v0.3.0 比較，沒有新增或遺失導覽操作，也沒有 TAP 判斷變化。

以上是離線辨識與輸入決策驗證，不是對方電腦實機驗證。拍屏曝光可能造成部分亮度差異，也不能從拍屏素材確認對方是否另有焦點或輸入傳遞問題。請以新版 EXE 重試；若仍停住，勾選「儲存本機診斷」並提供該次 sessions 資料以區分未識別與點擊無回應。診斷及使用者私人素材不隨 EXE 分發。
