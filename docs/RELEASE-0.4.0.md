# 0.4.0 — 簡約介面與釣魚目標

本次不修改 0.3.3 的拉扯控制算法、判定格追蹤、咬鉤／續局辨識或預設控制參數。

- 淺色簡約介面，Windows 原生控件、Segoe UI 字體，開始／停止按鈕等高等寬。
- 字體按 DPI 縮放，EXE 宣告 Per-Monitor V2；跨螢幕同步縮放字體和間距。視窗不超出目前螢幕工作區，較小螢幕配合較高縮放時可捲動全部內容。
- 「已釣獲」只計本次程式開啟後確認的魚獲卡片。漂流金屬等物品、啟動前的結果畫面和重複卡片不計。停止再開始保留本次累计；關閉重新開啟歸零，不讀寫計數存檔。
- 目標數量是本次程式開啟的累計目標，不是連勝或每次啟動目標。例如已釣 3、目標 5，再開始只需新增 2 條；達標後停在結果畫面，不再續局。0 表示不限。
- 停止快捷鍵預設 F9。可輸入 F1–F12、Esc、Pause 或 Ctrl／Alt／Shift 加英文字母／數字（例：Ctrl+Alt+Q）。運行期間鎖定設定，仍可點「停止」、關閉工具或切換視窗停止。
- 使用提供的紅色海盜魚去背景圖作為 EXE、視窗圖標，圖標素材包含在單一 EXE 中。
- 「儲存本機診斷」改為「開發者模式」，預設關閉。右側 ? 說明診斷包含狀態截图、魚獲、介面處理及時間戳追蹤，以及本機資料夾位置與回傳方式。資料不自動上傳，開啟診斷會寫入檔案並可能增加負載，與不保存釣魚計數的設定分開。

診斷目錄：`%LOCALAPPDATA%\HololiveFishingAuto\sessions\`。

## 驗證

99 項離線／模擬運行測試通過，其中包括六種語言在 100%、125%、150%、200% DPI 下的真實 Tk 控件幾何、自訂快捷鍵、兩次魚獲間夾失敗仍可達成總數目標、重複卡片不加計、停止後續釣只用剩餘目標、開發者說明包含實際目錄。

本次未操作遊戲或重新宣稱拉扯勝率。DPI 測試是控件／模擬 DPI 測試，不等同每種實體螢幕的截圖驗收。
