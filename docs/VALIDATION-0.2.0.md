# 0.2.0 驗證紀錄（2026-09-29）

以回退後的 0.1.0 原始碼為基礎。錄影、遊戲截圖與實測紀錄只留在本機忽略的 `sessions/`，不包含在 EXE 或版本庫。

## 問題與修正

- 原版實測釣獲後停在「繼續」畫面：瞬間按下／放開容易被遊戲漏掉，而且一次點擊後 `action_armed` 關閉，後續圖鑑、獎勵與下一步無法再處理。改成 65ms 結算點擊、跨幀確認、每 850ms 重試，最多 6 次。
- 魚覆蓋判定格時，顏色重心會偏移；反光與淺藍軌道背景也會使判定格缺失或魚圖示黏連。改成金色軌道內的獨立標記搜尋、判定格上下邊界、亮色保留與高飽和度魚遮罩。
- 控制死區依判定格高度縮小；使用速度預測提前煞車，接近魚時非阻塞快速脈衝。短暫遮擋最多預測 140ms；長時間失去標記就放開，HUD 消失不記為成功。
- 支援圖鑑、物品空白關閉、道具詳情及釣竿提示 X。提示只關閉，不點 GO，不前往商店或強化釣竿。
- 獎勵淡入時，紫色物品曾誤認為 TAP、打開物品詳情。已改成橫幅動畫期間禁止 TAP，且咬鉤標記限定在畫面下半部；正式關閉獎勵須同時有橫幅與 GET 字形證據。
- 以可重用的客戶區 GDI 緩衝擷取畫面；本機同尺寸量測從約 50ms 降至約 22ms。最後一批整體實測約 31.5 FPS（含結算點擊停頓），不是宣稱固定達到設定的 40 FPS。

## 兩段使用者錄影離線回放

按原始錄影標稱 60 FPS 時基，每秒取 10 個影格，僅分析，不輸入遊戲。金色軌道啟動／消失動畫的篩選與舊版略有不同，因此分別列出分母。

| 錄影 | 0.1.0 完整魚／格標記 | 新版完整魚／格標記 |
| --- | --- | --- |
| 14:18（約 143 秒） | 223 / 289 | 286 / 286 |
| 15:22（約 294 秒） | 471 / 471 | 467 / 467 |

這是標記可辨識覆蓋率，不是成功率，也不代表每個像素位置都已人工逐幀標注。已人工查看關鍵遮擋、反光、圖鑑、物品橫幅及道具詳情畫面。

## 實機批次

- 調整追蹤後的一批：6 / 6 明確 GET 魚獲結果。秋刀魚 153.4g、120.1g、227.1g、124.2g；海膽 202.6g；二星比目魚 2.5kg。每局可自動續竿，新圖鑑可自動關閉。
- 後續批次實際出現圖鑑與獲得物品／道具詳情堆疊，最後成功關閉獎勵、關閉圖鑑、按繼續並進入下一次拉扯。淡入 TAP 誤判在此被發現並修正。
- 最後低延遲版本一批：5 / 5 明確 GET 結果，四條秋刀魚 127.7g、170g、127.6g、156.2g，以及二星白帶魚 740.8g。另確認釣竿提示能關閉後續竿。
- 已實際以 F9 停止，輸出「F9：已停止」並正常返回；遊戲失焦或關閉 GUI 會停止及釋放按鈕。
- 打包後的 0.2.0 EXE 已以 GUI 一鍵開始實測，確認連續拉扯、自動續局，最後因遊戲失焦正常停止，未留下持續按住的輸入。

前期參數試驗與手動停止後遊戲自行失敗，不計入以上兩個完成批次。測試不宣稱涵蓋三星至五星魚、所有魚餌或所有未來版本。

## 回歸檢查

`python -m unittest discover -s tests -v`：53 項通過。新增案例涵蓋小格反光、魚遮擋、淺藍背景黏連、異常位置跳變、早煞車、近距離快速脈衝、彈窗鏈、無反應重試上限、按鈕像素抖動、獎勵淡入誤判與提示 X 優先於 GO。

舊版離線 CLI help 與人工物理基準也可執行；人工基準不冒充實機勝率。新 GUI 可選擇儲存本機診斷，預設不儲存、不錄影、不上傳。
