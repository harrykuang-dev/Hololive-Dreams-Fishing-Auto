# v0.3.0：六語介面與運行訊息

- 遊戲語言選項擴展為日本語、English、Indonesian、한국어、繁體中文、简体中文；名稱依遊戲語言選單顯示。
- 選擇語言後，助手介面、狀態、操作及釣獲訊息同步切換。預設繁體中文。此選項不會修改遊戲設定，請在遊戲內選擇相同語言。
- 長說明自動換行，改善日文、英文、印尼文及韓文的裁切。
- 命令列支援六種語言代碼及原有 `auto`；新增 `--target-streak 10`，僅在連續確認 10 次魚獲卡片後停止測試。GUI 預設持續釣魚。
- 保留 v0.2.5 的咬鉤辨識、拉扯控制、圖鑑及獎勵續關邏輯。

驗證：74 項離線測試通過，涵蓋六語文字與格式參數、核心辨識接受六語設定、訊息切換，以及 10 次確認魚獲後停止的測試流程。已打開候選 EXE 檢查語言選單及多語介面換行；使用者提供的語言切換錄影以 10Hz 離線回放，未產生模擬起鉤或導覽點擊。

六種語言各連續 10 局的實機驗證尚未完成，遊戲內各語言的完整釣魚術語也尚未全部核對。本版依使用者要求先發布，不能將離線測試視為六語實機穩定性證明。

下載單一 `Hololive-Fishing-Auto-v0.3.0.exe` 即可使用，無需另裝 Python。診斷截圖及本機影片不隨發布上傳。
