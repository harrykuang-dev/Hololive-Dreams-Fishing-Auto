# 0.2.3

修正魚尚未咬鉤時提前點擊的問題，保留 0.2.2 的拉扯及結算自動續局功能。

- 原因：雪地場景的紫紅色冰面反光，或浮標特寫，被只憑顏色／尺寸的舊版誤認為粉色咬鉤標記。
- 新版同時核對粉色提示、中央白色感嘆號及藍邊 TAP 字形；提示縮放與字形亮色高光仍可辨識。
- 起鉤需連續新鮮影格確認（至少 35ms），孤立或過期影格不觸發。同一提示只點一次，短暫掉幀不重複起鉤。
- 離線回放可指定完整遊戲客戶區，避免桌面遮擋導致裁切錯誤；版本對比載入該版視覺程式，不混用目前的模組。

## 驗證

使用者本次提供的約 18.85 秒錄影，全 1,131 幀離線回放：0.2.2 誤報 TAP 345 幀，0.2.3 誤報 0 幀。這是同一段未出現真實 TAP 的錄影對比，不是實機勝率。

22 張既有實機真實 TAP 截圖仍可辨識；3 張獎勵淡入與 2 張浮標特寫不觸發。另核對提示較小、游標重疊的真實 TAP 截圖。63 項回歸測試通過，包含 UI 特徵缺失、粉色反光、提示動畫縮放、近白色高光、連續影格、過期影格及防止重複起鉤。

使用新版獨立檔名 `Hololive-Fishing-Auto-v0.2.3.exe`；請先關閉舊版助手。錄影與診斷截圖只留本機，不包含於 EXE。
