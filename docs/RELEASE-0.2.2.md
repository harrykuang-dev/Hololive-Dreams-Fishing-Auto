# 0.2.2

Windows GUI 自動釣魚版本，下載 EXE 後點「開始釣魚」即可。請先關閉舊版助手；F9、停止按鈕或遊戲失焦可停止操作。

## 更新

- 小判定格自適應控制、速度預測提前煞車與近距離快速脈衝。
- 軌道內標記辨識、短暫遮擋容錯，降低反光與背景造成的誤判。
- 低延遲畫面擷取，自動處理結算、繼續、下一步及道具提示。
- 漂流金屬等素材獎勵優先按「繼續」，沒有按鈕才點空白。
- 修正圖鑑 X 藍色外圈與背景黏連時漏識別；搜尋內外輪廓並保留 X 字形檢查。
- 結算點擊保持 65ms，等待畫面切換；無反應最多重試 6 次後停止並顯示原因。

## 驗證與限制

56 項離線回歸測試通過。素材及圖鑑截圖以三種縮放尺寸驗證；目前實機圖鑑一次成功關閉，接著自動按繼續。先前低延遲版本最後一批 5／5 釣獲，包含二星白帶魚；這不是所有魚種的保證，三星以上尚待更多實測。

建議遊戲保持 16:9 並完整可見。不修改遊戲或讀取記憶體；診斷預設關閉，錄影與遊戲截圖未包含於發行檔。
