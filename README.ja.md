# Hololive Dreams Auto Fishing

[既知の問題と回避策](https://github.com/harrykuang-dev/Hololive-Dreams-Fishing-Auto/blob/main/docs/KNOWN_ISSUES.md)

[繁體中文](README.md) · [简体中文](README.zh-CN.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Indonesian](README.id.md)

Windows 版 **hololive Dreams** の自動さかな釣りアシスタントです。画面認識と通常のマウス入力で、食いつき、駆け引き、釣果の確認、次の釣りを操作します。

## ダウンロード

[GitHub Releases](https://github.com/harrykuang-dev/Hololive-Dreams-Fishing-Auto/releases/latest) の添付ファイルから `Hololive-Dreams-Fishing-Auto-v1.1.1.exe` をダウンロードしてください。

この EXE 1 個を実行するだけで利用できます。

## 主な機能

- 食いつきの表示を認識し、魚と判定エリアを追跡して駆け引きを制御。
- 釣果画面の「つづける／次へ」を操作し、新しい図鑑登録やアイテムのポップアップを閉じて釣りを続行。
- 繁體中文、简体中文、English、日本語、한국어、Indonesian の 6 言語に対応。言語を選択すると、アシスタントの画面とメッセージが切り替わります。
- 今回の釣果数を表示。目標数を設定すると、達成後に停止します。
- 開始キーは F8、停止キーは F9 が初期設定です。各設定欄をクリックして新しいキーや組み合わせを押すと変更できます。両方に競合するキーは設定できません。
- 実行履歴。
- 任意のローカル開発者診断モード。

## 使い方

1. ゲームを開き、魚餌を用意してさかな釣り画面に入ります。
2. EXE を起動し、「言語 / Language」で言語を選択します。
3. 目標数を設定します。`0` は無制限です。停止キーを変更する場合は設定欄をクリックして目的のキーを押します。
4. 開始をクリックするか、開始ショートカットを押します。ゲームのアクティブ化を試みますので、実行中はゲームを前面に表示し、画面全体が見える状態にしてください。
5. 停止キー、停止ボタン、またはウィンドウ切り替えで停止できます。再開時はカウントをゼロに戻し、目標の釣果数を最初から数え直します。

## 動作条件と制限

Windows 10／11 x64 と Windows 版ゲームが必要です。ゲームのクライアント領域を 16:9 に保ち、実行中は最小化、遮蔽、サイズ変更をしないでください。バックグラウンドでの釣り、および日本時間（JST）午前 5 時の日付切り替え後の釣りの継続には対応していません。魚餌の購入、マップ移動、ゲーム内資源の補充は自動で行いません。

キャラクターの配色、アニメーション、解像度、性能、ゲーム更新によって認識や操作に影響が出る場合があります。異常時は停止して診断データを提供してください。本ツールは非公式であり、ゲームのプロセスメモリ、セーブデータ、ゲームファイルを読み取ったり変更したりしません。Python プログラミングの学習および画像認識技術の研究・情報交換のみを目的としています。自動化ツールの使用に関するゲームの規定はご自身で確認してください。ゲームの健全な環境を損なう目的や、商用・営利目的で使用しないでください。本ツールの使用により生じた問題について、開発者は一切責任を負いません。

## 不具合報告と開発者モード

続行できない、追跡がおかしいなどの問題は [GitHub Issues](https://github.com/harrykuang-dev/Hololive-Dreams-Fishing-Auto/issues) から報告できます。

開発者モードを有効にして問題を再現すると、状態のスクリーンショット、釣果カード、追跡データ、処理時間をローカルに保存します。自動アップロードはありません。画像にはゲーム画面が含まれ、診断の有効化には追加の処理負荷がかかります。

右側の `?` から診断フォルダーを確認し、開くことができます。

JPEG をバックグラウンド保存し、1枚192 KiB以下、直近64枚と最新画面を保持します。追跡CSVは直近2区間（各4 MiB）を保持します。診断ZIPには任意の動画を含めません。

```text
%LOCALAPPDATA%\HololiveFishingAuto\sessions\
```

パスは現在の Windows アカウントによって決まり、実行ごとに日時名のフォルダーを作成します。アプリのバージョン、ゲームの言語／キャラクター、解像度、Windows の表示倍率、問題の説明、停止後に自動生成される `diagnostics-YYYY-MM-DD_HH-MM-SS.zip` を添付してください。送信前に画像に公開したくない情報がないか確認してください。
